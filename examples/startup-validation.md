# Startup Validation Example

Please validate the following startup idea:

**Idea:** I want to build a platform that connects freelance writers with small businesses that need blog content.

**Context:**
- Target market: US-based small businesses (1-50 employees).
- Pricing: Subscription-based, starting at $299/month for 4 blog posts.
- Differentiation: We vet all writers and guarantee turnaround times.

**Questions:**
1. Is this a strong opportunity?
2. What are the main risks?
3. What should we validate next before building the platform?
