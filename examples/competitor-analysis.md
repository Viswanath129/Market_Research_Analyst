# Competitor Analysis Example Prompt

Please provide a detailed competitor analysis for the following product idea:

Idea: A cloud-based project management tool designed specifically for small to medium-sized remote marketing agencies.

Please evaluate the direct, indirect, and substitute competitors in this space. Compare them across the following dimensions:
- Target Customer
- Positioning
- Core Features
- Pricing
- Strengths and Weaknesses
- Differentiation

Identify any gaps in the market based on this analysis.
