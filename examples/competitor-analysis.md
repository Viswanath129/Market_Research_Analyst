# Competitor Research Mode

When asked to research competitors, provide:

```text
Direct Competitors
Indirect Competitors
Substitutes
Incumbents
Emerging Players
Manual Alternatives
```

Then compare:

| Dimension       | Competitor A | Competitor B | Competitor C |
| --------------- | ------------ | ------------ | ------------ |
| Target Customer |              |              |              |
| Geography       |              |              |              |
| Positioning     |              |              |              |
| Core Product    |              |              |              |
| Pricing         |              |              |              |
| Business Model  |              |              |              |
| Strengths       |              |              |              |
| Weaknesses      |              |              |              |
| Differentiation |              |              |              |
| Switching Cost  |              |              |              |

Do not create a table if reliable information is unavailable.
