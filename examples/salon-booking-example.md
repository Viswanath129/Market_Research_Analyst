# Salon Booking System Example Prompt

I want to build a salon booking system in India.

Please investigate the following:
- What does the current Indian salon market look like (independent vs chains)?
- How do customers currently book (phone, WhatsApp, existing software)?
- What existing platforms serve this market?
- What are the common switching barriers and problems (like no-shows, staff scheduling)?
- Is there an underserved segment or specific problem that could justify a new product in this space?

Provide a verdict on the viability of this opportunity.
