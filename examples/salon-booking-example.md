# Salon Booking Example

I am considering building a new salon booking system for independent salons in the UK.

Before I start writing code, please analyze this market:

1. How do independent salons currently handle bookings?
2. Who are the main incumbents in this space?
3. What are the switching costs for a salon to change their booking software?
4. Is there a genuine gap in the market, or is it already saturated?
5. What specific evidence would I need to prove this is worth building?
